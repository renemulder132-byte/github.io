Orvo

Orvo is a private home assistant that runs on the owner's own computer. It controls lights, heating, music and the TV, and it can read the owner's Gmail and Google Calendar, send an email or create a calendar event when the owner explicitly confirms it.

Orvo is a personal project used only by its owner. It is not offered to the public and has no user accounts.

Google data

Orvo uses Gmail (read, send) and Google Calendar (read, create events) only for the owner's own account. Data stays on the owner's computer and is never sold or shared. See the privacy policy and the terms of service.
